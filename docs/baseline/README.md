# docs/baseline —— 原型截图基线(2026-09-30)

`smart-naive-table-design.html` 的四个模块 × 明 / 暗 × 两种视口,共 16 张。**不随包发布**,用来在以后改样式时对照「有没有无意中变样」。

命名:`m{模块号}-{light|dark}-{视口宽}.png`,视口 1440×900(桌面,实际是中档:容器 1100)与 390×844(手机,窄档)。

| 模块 | 内容 |
|---|---|
| m1 | 搜索区独立卡片(模式 1) |
| m2 | 按钮与工具栏(模式 2 条件构造器) |
| m3 | 过滤筛选(列头漏斗) |
| m4 | 排序(列头箭头 + 多列排序) |

重新生成:在本目录的上一级起 `python -m http.server 8765`,用 Playwright 打开 `http://localhost:8765/smart-naive-table-design.html`,依次点侧栏四个模块、切换主题后整屏截图(390 宽时侧栏收起,改用 `emulateMedia({ colorScheme })` 后刷新)。数据是确定性伪随机,重复生成应逐像素一致(字体渲染差异除外)。

注意:这是**原型**的基线,不是库的视觉回归;库落地后应另建基于真实组件的基线。
