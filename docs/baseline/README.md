# docs/baseline —— 原型截图基线

`smart-naive-table-design.html` 的 14 个模块 × 明 / 暗 × 两种视口,共 56 张。**不随包发布**,用来在以后改样式时对照「有没有无意中变样」。

命名:`m{模块号}-{light|dark}-{视口宽}.png`(`m1-light-1440.png` … `m14-dark-390.png`),视口 1440×900(桌面,实际是中档:容器 1100)与 390×844(手机,窄档)。整屏截图(含侧栏;390 宽时侧栏收成顶部模块条)。

| 模块 | 侧栏位置(两级目录) | 内容 |
|---|---|---|
| m1 | 查询 · 搜索表单 | 搜索区独立卡片(模式 1) |
| m2 | 查询 · 条件搜索 ★ | 按钮与工具栏(模式 2 条件构造器) |
| m3 | 查询 · 表头过滤 ★ | 过滤筛选(列头漏斗) |
| m4 | 查询 · 多列排序 | 排序(列头箭头 + 多列排序) |
| m5 | 列 · 多级表头与固定列 | 列类型与宽表(固定列 / 多级表头 / 展开 / 合计) |
| m6 | 列 · 字典、标签与格式化 ★ | 字典与格式化(字典标签 / money / 日期 / 空值;卡片内搜索) |
| m7 | 列 · 列设置 ★ | 列设置与持久化(`storageKey`,截图前已清空 localStorage) |
| m8 | 数据 · 加载与错误处理 | 数据状态(`immediate:false` 首屏:`NEmpty`「无数据」,未请求;卡片内搜索) |
| m9 | 数据 · 增删改弹窗 | 新增 / 编辑 / 删除(CRUD) |
| m10 | 行 · 行拖拽排序 | 行拖拽排序(「工序」子表) |
| m11 | 行 · 主从联动 | 主从联动与行交互(部门树 + 表格,窄档树变下拉) |
| m12 | 布局 · 嵌入式表格 | 精简与嵌入形态(入库明细子表 + 不铺满的物料单据表;页面顶部) |
| m13 | 不在侧栏;页面保留,`enterModule('i18n')` 可进 | 多语言与页面底色 |
| m14 | 数据 · 可编辑表格 | 可编辑表格(Excel 式单元格编辑 + 按数据类型推断控件;`enterModule('excel')`) |

侧栏是**两级目录**(查询 / 列 / 行 / 数据 / 布局 5 组,子页常显、无编号,见 `../smart-naive-table-design.md`「设计模块重新分类与命名」);分组只是呈现,`m1`–`m14` 文件名、模块键与 `enterModule('键')` 与分组无关。

重新生成:在本目录的上一级(`docs/`)起 `python -m http.server`(任意端口),用 Playwright 打开 `http://127.0.0.1:{端口}/smart-naive-table-design.html`,**每个视口、每个主题各重新加载一次页面**(先 `localStorage.clear()`),然后对每个模块依次:`enterModule('{search|toolbar|filter|sort|wide|dict|persist|states|crud|drag|ms|embed|i18n|excel}')` → 鼠标移到 (2,2) 避免悬停态 → 等 1.3 秒(模块 6 等 1.8 秒,字典异步 0.9 秒;其余模块的 mock 后端延迟 0.42 秒)→ 整屏截图。主题用 `runAct('theme', 'light'|'dark')` 切(390 宽侧栏收起,没有按钮可点)。**截图前确认外壳开关在默认值**:语言中文、页面底色灰、密度紧凑(`state.lang / pageBg / compact` = `zh / gray / true`)。数据是确定性伪随机,重复生成**逐字节一致**(可用 md5 校验)。

注意:这是**原型**的基线,不是库的视觉回归;库侧用 `tools/parity` 与原型逐项读数对照(见 `tools/parity/README.md`)。
